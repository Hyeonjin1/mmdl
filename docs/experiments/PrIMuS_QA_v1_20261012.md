문항 유형은 첫 일반 음표의 음높이(옥타브 포함), 점을 포함한 기보 음가, 첫 음자리표, 첫 두 일반 음표 사이의 부호 있는 반음 간격이다. 첫 세 유형은 각각 87,673문항, 반음 간격은 87,672문항이다. 일반 음표가 1개인 악보 1개에서는 간격 문제를 생성하지 않았다. 장·단·완전 등의 음정 품질이나 화음 문제는 생성하지 않는다. 음가는 악보에 쓰인 음표값이며 페르마타의 실제 연장, 붙임줄 합산 길이, 셋잇단음표 시간이나 템포를 추론하지 않는다. 질문에도 이러한 기준을 명시했다.

4개 선택지는 고정 seed 3407로 생성하고 정답 위치를 섞었다. `answer`는 A–D, `source_answer`는 해석된 값이다. MMDL 기존 MCQ의 question/options/answer/image 필드와 맞췄다. annotation 경로와 계산 근거는 감사 메타데이터로만 보존하며 질문에는 넣지 않는다. E8 학습 설정이나 실행기는 연결하지 않았고 학습은 시작하지 않았다.

## split과 중복 방지

공식 PrIMuS QA나 공식 split이 아니다. 원본 ID의 첫 하이픈 앞 작품 식별자, 동일 normalized semantic 내용, 동일 PNG SHA-256으로 연결 그룹을 만든 후 seed 3407의 해시로 약 80/10/10 split을 배정했다. 비율은 목표값이고 실제 문항 비율은 위 표와 같다. 원본 annotation은 정규화 후 해시 계산에만 사용하며 원본 파일을 변경하지 않았다.

작품 번호의 의미는 파일 이름에 근거한 추정이다. 전조·유사 선율 등 근사 중복 전체를 검출한 것은 아니다. 네 유형이 동일 이미지에서 파생되므로 실제 독립 악보 수는 350,691개가 아니라 87,673개다. 작업명·공식 QA·공식 split을 혼동하지 않는다.

## 검증

- 모든 사용 이미지의 PNG 검사와 PNG/semantic/agnostic/MEI/regular_pae.pae 연결 확인. macOS `._` 보조 파일은 원본 악보로 집계하지 않음.
- 고정 무작위 표본 256개에서 MEI와 semantic의 첫 일반 음표 음이름·옥타브·기보 음가·음자리표를 대조하고 PNG를 실제 decode함. 이 표본에서는 모두 일치. 조표·임시표 적용값은 semantic annotation을 사용했으며 전체 MEI 재해석으로 독립 검증한 것은 아님.
- 시각 표본 1개에서 첫 음 Bb5, 4분음표, G2 음자리표, 다음 음 Eb5로 이어지는 -7반음과 annotation을 확인함. 이는 전체 인간 검수 완료를 의미하지 않음.
- 저장된 QA 전체 350,691행의 JSON 읽기, ID 유일성, 4개 선택지 중복 없음, 정답 letter–값 일치, 근거 token의 질문 비노출 확인.
- 작품·연결 그룹·동일 이미지·동일 semantic의 split 교차 중복 0. 저장된 JSONL SHA-256이 manifest와 일치.
- 제외 파일과 이유는 로컬 rejected.json에 보존. 자동 생성 템플릿 QA이며 사람 작성 QA의 난이도·다양성을 보장하지 않음. 첫 음과 초기 기호 위주여서 전체 악보 이해 성능으로 확대 해석하면 안 됨.
