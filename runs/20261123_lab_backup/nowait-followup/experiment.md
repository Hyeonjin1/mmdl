# MMMU NoWait 후속 실험

과거 팀 B0에서 8,192토큰 한도에 도달해 최종 답을 추출하지 못한 객관식 40문항에 차단 목록 정제와 4,096토큰 답안 전환을 각각 적용했다. 모든 결과의 분모는 같은 40문항이다.

| 조건 | 확인된 정답 | 채점 보류 | 생성 토큰 | 과거 B0 대비 감소율 | 길이 종료 / 반복 중단 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 과거 팀 B0 | 0/40 | — | 327,680 | — | 40 / 0 |
| NoWait | 8/40 | 2 | 245,360 | 25.12% | 20 / 4 |
| NoWait · 차단 목록 정제 | 8/40 | 2 | 244,736 | 25.31% | 22 / 5 |
| **NoWait · 4,096토큰 답안 전환** | **19/40** | **1** | **143,648** | **56.16%** | **0 / 0** |

채점 보류는 확인된 정답 수에 포함하지 않았다. 생성 토큰은 조건별 40문항 전체의 출력 합계다.

## 구현

- 차단 목록 정제는 디코드 후 공백과 대소문자를 정규화해 사전 고정 예외 (anyone, button, company, know, knowledge, mother, ohio)에 정확히 일치하는 토큰만 제외했다. 마스크는 918개에서 886개로 줄었다. 생성 예산과 채점 조건은 기존과 동일하다.
- 답안 전환은 918개 원래 마스크에서 4,096토큰 한도까지 첫 요청을 실행한다. 그 전에 종료하면 기존 흐름을 유지하고, 한도에 도달하면 원래 이미지와 생성 토큰을 붙여 최종 선택지만 요청한다. 추가 생성 한도는 128토큰이다. 이어받은 멀티모달 프롬프트의 토큰을 대조했다. 전환 후에는 두 번째 요청의 출력으로 답을 채점했다.
- 답안 전환은 29문항에서 발동했다. 재요청 지시문은 합계 1,102 입력 토큰이며, 재요청 프롬프트에는 이미지와 기존 생성 토큰을 포함해 합계 156,034 입력 토큰이 들어갔다. 이 입력 비용은 표의 생성 토큰에서 제외한다.

## 답안 전환으로 확인한 정답 19건

- NoWait에서도 확인한 정답 8건을 유지했다.
- NoWait에서 채점 보류된 건축·공학 26번과 재료 9번에서도 정답을 확인했다.
- 나머지 9건은 회계 22번, 건축·공학 9번, 전자공학 7번, 에너지·전력 4번·8번·9번, 재료 22번, 수학 16번, 음악 23번이다.

답안 전환에서는 에너지·전력 13번이 채점 보류로 남았다. 차단 목록 정제의 보류 문항은 건축·공학 26번과 재료 9번이었다.
